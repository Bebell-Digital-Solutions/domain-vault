## ⚡ Why DOMAIN VAULT?

Replace messy spreadsheets with a high-performance system designed for domain investors, developers, and agencies.
**DOMAIN VAULT** never asks for registrar credentials and never scrapes your accounts. Add a domain, hit the WHOIS button to pull the creation and expiry dates, set your costs, and it's tracked.

No API keys. No OAuth. Just your data, securely in one place.

## 🚀 Key Features

* **📊 All-in-One Dashboard:** View your entire domain portfolio at a glance, including total domains, annual costs, upcoming renewals, and provider distribution.
* **📅 Automated Renewals Calendar:** Sync expiration dates directly to Google Calendar or download `.ics` files. Get WhatsApp reminders before you lose valuable digital real estate.
* **🏢 Multi-Provider Vault:** Store secure credentials for GoDaddy, Namecheap, Cloudflare, IONOS, and custom registrars in one encrypted vault.
* **🔐 Zero-Knowledge Security:** Your vault lives in a Supabase Postgres database protected by Row-Level Security (RLS) hosted on AWS, meaning only you can read your rows. Credential storage uses zero-knowledge AES-256 client-side encryption.
* **🌐 Live DNS Inspector:** Query live DNS records (A, TXT, MX, CNAME) directly from the dashboard to verify propagation and structural integrity without opening a terminal.
* **📈 Financial Reporting:** Track renewal costs by month, visualize your true domain investment, and export comprehensive CSV reports to hand off to your accounting team.
* **🌍 Bilingual UI:** Seamlessly switch between English and Español with one click.

## 💡 How It Works (Zero-Config Workflow)

1. **Add Domains:** Manually add your domains or use the **Auto-fill using WHOIS** tool to instantly fetch registration and expiry dates.
2. **Set Costs:** You decide what counts as a purchase and an annual renewal cost.
3. **Monitor:** Use the dashboard to get warned about upcoming expirations (e.g., "Expiring in 30 Days") and DNS errors.

## ❓ Frequently Asked Questions

<details>
  <summary><b>Which domain registrars are currently supported?</b></summary>
  <br>
  We currently offer native 1-click API integration for Cloudflare, GoDaddy, Namecheap, AWS Route 53, IONOS, Porkbun, and Google Domains. For unsupported registrars, you can manually add domains and track them via WHOIS lookups.
</details>

<details>
  <summary><b>How often does Domain Vault sync my portfolio?</b></summary>
  <br>
  By default, the Vault runs a secure background sync every 24 hours to check for status changes, upcoming renewals, and DNS modifications. Paid tiers allow you to force manual syncs at any time directly from the dashboard.
</details>

<details>
  <summary><b>Is my data and provider login information secure?</b></summary>
  <br>
  Absolutely. Your data is stored securely in a Supabase PostgreSQL environment protected by Row-Level Security (RLS). Any provider credentials you choose to store are encrypted client-side using AES-256 before transmission.
</details>
